Deutsch – technische Datenschutzhinweise

Die aktuelle Anwendung verarbeitet Ihre Themenauswahl und Freitexte nach dem geprüften Quellcode im Browser. Eine eigene Nutzerdatenbank, Anmeldung oder gezielte Übermittlung der Eingaben an einen NarcoRisks-Anwendungsserver sind nicht implementiert. Beim Kopieren oder Herunterladen können Inhalte auf Ihrem Gerät gespeichert werden. Bitte geben Sie keine echten Patienten- oder sonstigen sensiblen personenbezogenen Daten ein.

GitHub Pages verarbeitet beim Website-Aufruf technische Verbindungsdaten. GitHub dokumentiert, dass Besucher-IP-Adressen zu Sicherheitszwecken protokolliert werden. Die Anwendung ruft den Katalog von raw.githubusercontent.com und externe Schriftarten von fonts.googleapis.com bzw. fonts.gstatic.com ab; dabei können IP-Adressen und Verbindungsdaten durch diese Dienste verarbeitet werden. Im geprüften Anwendungscode sind keine eigenen Analyse-/Tracking-Skripte oder eigenen Cookies vorgesehen; Host- oder Browserverarbeitungen sind damit nicht ausgeschlossen.

Die technische Bereitstellung und Sicherheit können, soweit der Projektbetreiber für die konkrete Verarbeitung verantwortlich ist, auf berechtigte Interessen gemäß Art. 6 Abs. 1 lit. f DSGVO gestützt werden. Eigenständige Verantwortlichkeiten, Löschfristen und mögliche Drittlandübermittlungen der Anbieter sind gesondert zu prüfen: GitHub Privacy Statement · Google Datenschutzhinweise. Die öffentlich bestätigten Anbieterinformationen nennen derzeit noch keine verifizierte ladungsfähige Anschrift oder direkte E-Mail. Eine vollständige betreiberbezogene Art.-13-DSGVO-Prüfung, einschließlich Verantwortlichem und Betroffenenrechten, bleibt offen.

English – technical privacy information

The reviewed code processes your topic selections and free text in the browser. It does not implement a NarcoRisks user database or app-server submission of form entries. Copying and downloading can store content on your device. Do not enter real patient or other sensitive personal data.

GitHub Pages processes connection data and states that visitor IP addresses are logged for security. The application fetches its JSON catalogue from raw.githubusercontent.com and fonts from Google Fonts; these requests may disclose IP addresses and other technical data. No project tracking or analytics scripts were identified in the reviewed code, but host/browser processing is not excluded. Actual provider roles, retention and transfers require separate review. See GitHub, Google, and public provider details.

Français – informations techniques sur la confidentialité

Selon le code examiné, les thèmes et textes saisis sont traités dans le navigateur, sans base d’utilisateurs NarcoRisks ni envoi du formulaire vers un serveur de l’application. La copie ou le téléchargement peuvent enregistrer des données sur votre appareil. Ne saisissez pas de données réelles ou sensibles de patients.

GitHub Pages traite des données de connexion et indique enregistrer les adresses IP pour la sécurité. Le catalogue JSON est chargé depuis raw.githubusercontent.com et les polices depuis Google Fonts ; les fournisseurs peuvent recevoir des adresses IP et des métadonnées de connexion. Aucun script de suivi propre au projet n’a été identifié, sans exclure les traitements de l’hébergement ou du navigateur. Voir GitHub, Google et les informations sur l’éditeur. Les responsabilités et délais de conservation exigent une vérification supplémentaire.
